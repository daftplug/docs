The free version on WordPress.org is a complete, working PWA: manifest, service worker, offline caching, an install banner, push notifications, and analytics. Pro adds the settings listed on the right of each table below.

Locked settings stay visible in the admin with a **Pro** badge, so you can always see what a license would add without installing anything.

## General

Nothing on this tab is gated. Platform support is available in both versions.
