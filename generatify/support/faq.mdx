## Cost and keys

<AccordionGroup>
  <Accordion title="Do I need an API key?">
    Only for some features. Toxicity checking, alt text, related posts, smart compose, the content summary button, the page agent, and the browser AI tools all work with no key at all, because they run in the visitor's browser or on your own server.

    The copilot, content generation, meta descriptions, and helpdesk conversation mode call an AI provider, and those need a key.
  </Accordion>

  <Accordion title="Does Pro include AI usage?">
    No. A license unlocks the connectors and the features that use them. The provider bills you separately for what you send. DaftPlug never sees your usage and cannot cap it.
  </Accordion>

  <Accordion title="How much will it cost to run?">
    It depends entirely on which features you enable. Meta descriptions and tag suggestions are small requests. Generated images are the most expensive item by a wide margin. Helpdesk conversation mode is the only feature whose volume your visitors control rather than you.

    Set a spending limit in your provider's dashboard before enabling anything visitor-facing.
  </Accordion>

  <Accordion title="Can I use my ChatGPT Plus subscription?">
    No. A consumer subscription and API access are separate products with separate billing. You need a key from the developer console.
  </Accordion>

  <Accordion title="Is my content sent to the AI provider?">
    Only for the features that call one, and only what those features need: the post you are generating from, the pages you selected as helpdesk knowledge, the content the copilot reads to answer you. The free features send nothing anywhere.
  </Accordion>
</AccordionGroup>

## The copilot

<AccordionGroup>
  <Accordion title="Can it change my site without asking?">
    No. Every write returns a preview and waits for your confirmation before anything happens. This is enforced in the plugin rather than requested in the prompt, so an assistant that decides to skip asking still cannot write.
  </Accordion>

  <Accordion title="Can it edit theme and plugin files?">
    Yes, within limits: inside `wp-content` only, on an allowlist of source file extensions, honoring `DISALLOW_FILE_MODS` and `DISALLOW_FILE_EDIT`, with the previous version copied to a backup folder first. See [developer abilities](/generatify/guides/copilot#developer-abilities).

    Work on staging when asking it to modify code.
  </Accordion>

  <Accordion title="Are my conversations stored on the site?">
    No. They are kept in your browser's local storage. They do not appear in your database, do not follow you to another machine, and are cleared when you clear site data.
  </Accordion>

  <Accordion title="Can other administrators see my conversations?">
    No, for the same reason. Each administrator has their own history in their own browser.
  </Accordion>
</AccordionGroup>

## Features

<AccordionGroup>
  <Accordion title="Will generated content hurt my search rankings?">
    Search engines rank pages on whether they are useful, not on how they were typed. A draft you have fact-checked, cut, and added your own experience to is a good page. The same draft published untouched reads like everyone else's, which is the actual risk.

    Check every fact before publishing. Generated text is equally confident when it is wrong.
  </Accordion>

  <Accordion title="What is the difference between the page agent and the helpdesk agent?">
    The page agent acts: a visitor says what they want and it works through your site to do it. The helpdesk agent answers: it responds to questions and points at your help articles.

    They also differ in cost. The page agent runs in the visitor's browser and costs you nothing. The helpdesk agent in conversation mode spends your API credit on every message.
  </Accordion>

  <Accordion title="What is WebMCP?">
    A way for a page to hand tools to an AI agent built into the browser, so the agent can search your content or look up a product instead of guessing from the page. It only works in browsers that support it, and it exposes read-only tools plus, on WooCommerce, adding to the cart. See [browser AI tools](/generatify/guides/browser-ai-tools).
  </Accordion>

  <Accordion title="Does the toxicity checker replace my spam plugin?">
    No. It runs in the commenter's browser before submission, so anything posting directly to WordPress bypasses it entirely. It stops a real person writing something abusive; it does nothing about bots. Keep your spam protection.
  </Accordion>

  <Accordion title="Does it work with WooCommerce?">
    Yes. The browser AI tools add product search, stock lookups, and add-to-cart when WooCommerce is active. Content generation can be extended to products with a filter.
  </Accordion>
</AccordionGroup>

## Licensing

<AccordionGroup>
  <Accordion title="Is Generatify sold on its own?">
    Pro is part of the DaftPlug membership. One license covers Generatify and every other DaftPlug Pro plugin, and the plans differ only in how many sites you can activate on.
  </Accordion>

  <Accordion title="What happens to my settings if the license lapses?">
    Nothing is deleted, including your API keys. Pro features stop working and the free ones carry on. Reactivating restores everything.
  </Accordion>

  <Accordion title="Can I move a license to a different site?">
    Yes. Deactivate it on the old site to free the activation, then activate on the new one.
  </Accordion>
</AccordionGroup>
